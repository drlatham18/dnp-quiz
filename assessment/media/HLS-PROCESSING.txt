Processing objective
--------------------

The objective of the processing workflow was to create a curated and normalized
Heart Set (HS) and Lung Set (LS) suitable for research, educational use, health
simulation, and development of auscultation training resources.

The processing aimed to improve consistency and comparability across audio
recordings while preserving the original acoustic characteristics of the source
material.

Processing workflow
-------------------

1. Source dataset review
   The original HLS-CMDS dataset and metadata were reviewed to identify the
   Heart Set (HS), Lung Set (LS), and relevant metadata fields.

2. Selection and organization
   The Heart Set (HS) and Lung Set (LS) subsets were selected and organized
   according to sound/pathology category and auscultation/recording location.

3. Integrity and consistency check
   Each selected audio file was checked for basic integrity, readability,
   expected file format, and consistency with the corresponding metadata.

4. Manual quality control
   Recordings were individually reviewed by UNIWA ICU-LAB members to identify
   basic inconsistencies or file-level issues before standardization.

5. Audio normalization
   Each audio file was manually processed using Audacity 3.7.5. Normalization
   was applied to improve comparability across recordings.

   Normalization parameters:

   Normalize:
     ApplyVolume="1"
     PeakLevel="-1"
     RemoveDcOffset="1"
     StereoIndependent="0"

6. Metadata organization
   Dataset counts, labels, and recording locations were organized and documented
   in the README file and accompanying subset summaries.

7. Documentation
   The processing workflow, license statement, citation information, and dataset
   structure were documented in:
     - README.txt
     - LICENSE.txt
     - CITATION.cff
     - PROCESSING_LOG.txt
     - heart_set/HEART_SET_SUMMARY.txt
     - heart_set/metadata_cardiac_updated.json
     - lung_set/LUNG_SET_SUMMARY.txt
     - lung_set/metadata_respiratory_updated.json
     - MANIFEST_SHA256.txt

Known limitations
-----------------

This adapted dataset version is based on the original HLS-CMDS dataset, which
was recorded from a clinical manikin using a digital stethoscope. Therefore,
the recordings should not be interpreted as direct recordings from human
patients.

This dataset is intended for research, education, simulation, and development
purposes. It is not intended for clinical diagnosis, clinical decision-making,
or patient care.
