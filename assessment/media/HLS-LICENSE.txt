Modification notice
-------------------

This version is an adapted/derivative version of the original HLS-CMDS dataset.

The modifications include:
  - selection and organization of the Heart Set (HS) and Lung Set (LS);
  - manual review and quality control of the recordings;
  - basic integrity and consistency checking;
  - metadata organization;
  - audio normalization using Audacity 3.7.5;
  - documentation of processing parameters and dataset structure.
