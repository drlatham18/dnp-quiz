# Nursing study companion — ordered production squawk list

Updated September 28, 2026 after owner decisions. This is the ordered work plan, not a declaration that the production profile has been implemented. The broader GitHub preview remains available for testing. No spending cap or external destination has been authorized.

## Decisions settled

| Area | Owner decision |
| --- | --- |
| Geography and audience | U.S. adult nursing students and licensed nurses; independent study. Institutional adoption deferred. |
| Product promise | Study companion; no CE/contact-hour credit and no patient-care use. |
| Initial economics | Limited free content breadth, unlimited repeat practice and a daily question from the reviewed bank. No daily session cap. |
| Accounts | Free tier has no account; progress is local. Account-based cross-device sync is a future paid-tier perk. |
| Initial content | RN foundations, heart sounds, lung sounds, skin/wounds and basic laboratory reports. Imaging and NP/DNP material stay in testing for later. |
| Community | Submissions/publishing deferred. Production daily questions must use the reviewed, version-controlled bank. |
| Monetization | Paid tier later; ads later. Initial release is ad-free. |
| Business | Proposed operator: Latham Counseling Services, LLC, Tennessee. Possible Mahtal Applied Services brand; setup and legal suitability need work. |
| Review and authority | Daniel will find three trained nurse reviewers and handle verification/final approval. |
| Platform | Web versus native remains undecided pending acquisition/retention research. Three budget operating options are prepared, not selected. |
